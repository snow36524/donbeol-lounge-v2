## 마진계산기 계산 기준 (엑셀 "쿠폰적용전 마진계산기"와 일치)
- 중국 원가 = 위안 × (환율+부대비용, 기본 300원)
- 총원가 = 원가 + 입출고배송비×1.1 + 판매수수료×1.1
- 순수익 = (판매가 − 총원가) ÷ 1.1
- 최대광고비 = 순수익 × 0.909
- E-ROAS = 판매가 ÷ 최대광고비
- (주의) 상단 "1개 팔면 남는 돈"·마진율은 아직 부가세 차감 전 금액
